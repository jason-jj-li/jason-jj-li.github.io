# 生命历程视角的几个提醒
如果只想写一篇纯文本文章，直接在 `content/blog/` 放一个 `.md` 文件即可。下面这些内容会被前端渲染成 HTML。

## 研究出发点
- 早期经历会在几十年后仍然影响健康；写作时可以列出假设、数据来源与变量定义。
- 文章可以内嵌链接（例如 [CHARLS 官网](http://charls.pku.edu.cn/en)）或图表占位符。

## 可复用的提纲
1. 研究问题与文献空白
2. 数据与样本选择
3. 变量与测量（暴露、结局、协变量）
4. 分析设计（分层、敏感性分析）
5. 结果要点与局限

### 小结
单纯的 Markdown 适合发布观点、笔记或更新日志。只要保留 frontmatter（上方 `---` 块）就能让站点自动识别标题、日期与摘要。
