Python Statistical Analysis in Practice — 01: Simulation Basics¶

Author: Jason JJ Li · Peking University Institute of Population Research

This first tutorial introduces the core technique used throughout this series: learning statistics by generating your own data. When you simulate data with known parameters, you always know the "true answer" — so you can directly verify how well any statistical method works.

The four-step loop used in every post:

  1. Simulate — generate data with known parameters
  2. Estimate — apply a statistical method
  3. Verify — compare estimates against the known truth
  4. Explore — vary conditions and observe how results change

Part 2: Why Simulated Data?¶

Traditional statistics courses rely on real datasets — but you never know the true parameter values, so you can never verify whether your estimates are accurate.

Simulated data solves this:

Problem with real data Simulation solution
Hard to obtain One line of code generates any dataset
True answer unknown We set the true parameters ourselves
Can't test edge cases Precisely control sample size, distributions, missing rates
Hard to reproduce Random seed guarantees identical results
Effect size is abstract Set the true effect, then observe estimated effect

Part 5: Building the Simulation Toolkit¶

These five functions are reused in every subsequent post. Providing them here once avoids repetition.

In [5]:
# =========================================================
#  simulation_toolkit.py  —  core helpers for this series
# =========================================================

_RNG = np.random.default_rng(42)

def set_seed(seed: int = 42) -> None:
    """Reset the global RNG with a new seed."""
    global _RNG
    _RNG = np.random.default_rng(seed)
    print(f'Random seed set to: {seed}')


def simulate_normal(n: int, mean: float = 0, std: float = 1, seed: int = None) -> np.ndarray:
    """Generate n samples from Normal(mean, std)."""
    rng = np.random.default_rng(seed) if seed is not None else _RNG
    return rng.normal(loc=mean, scale=std, size=n)


def simulate_two_groups(
    n1: int, n2: int, mean1: float, mean2: float,
    std: float = 1, seed: int = None
) -> pd.DataFrame:
    """Generate two independent normal samples and return as a tidy DataFrame."""
    rng = np.random.default_rng(seed) if seed is not None else _RNG
    g1 = rng.normal(loc=mean1, scale=std, size=n1)
    g2 = rng.normal(loc=mean2, scale=std, size=n2)
    return pd.DataFrame({
        'group':     ['Group A'] * n1 + ['Group B'] * n2,
        'value':     np.concatenate([g1, g2]),
        'true_mean': [mean1] * n1    + [mean2] * n2,
    })


def simulate_regression(
    n: int, beta0: float = 0, beta1: float = 1,
    noise_std: float = 1, seed: int = None
) -> pd.DataFrame:
    """Generate data from y = beta0 + beta1*x + epsilon."""
    rng = np.random.default_rng(seed) if seed is not None else _RNG
    x = rng.uniform(0, 10, n)
    y_true = beta0 + beta1 * x
    y = y_true + rng.normal(0, noise_std, n)
    return pd.DataFrame({'x': x, 'y': y, 'y_true': y_true})


def simulate_logistic(
    n: int, beta0: float = 0, beta1: float = 1, seed: int = None
) -> pd.DataFrame:
    """Generate binary outcome data from a logistic model."""
    rng = np.random.default_rng(seed) if seed is not None else _RNG
    x = rng.uniform(-3, 3, n)
    p = 1 / (1 + np.exp(-(beta0 + beta1 * x)))
    y = rng.binomial(1, p)
    return pd.DataFrame({'x': x, 'p_true': p, 'y': y})


def verify_estimate(
    estimate: float, true_value: float, label: str = 'Parameter'
) -> float:
    """Print a comparison table and return relative error (%)"""
    rel_err = abs(estimate - true_value) / abs(true_value) * 100
    bias    = estimate - true_value
    print(f'{label}:')
    print(f'  True value  : {true_value:.4f}')
    print(f'  Estimate    : {estimate:.4f}')
    print(f'  Bias        : {bias:+.4f}')
    print(f'  Relative err: {rel_err:.2f}%')
    return rel_err


print('simulation_toolkit loaded. Available functions:')
print('  set_seed(), simulate_normal(), simulate_two_groups(),')
print('  simulate_regression(), simulate_logistic(), verify_estimate()')

Part 7: Parameter Sweep — How Sample Size Affects Accuracy¶

The Law of Large Numbers says that estimates improve as n increases. Let's verify this directly.

In [8]:
TRUE_MEAN = 100
TRUE_STD  = 15

sample_sizes   = [10, 30, 50, 100, 300, 500, 1000, 3000]
n_repetitions  = 500  # repeat each sample size 500 times

results = []
for n in sample_sizes:
    rng = np.random.default_rng(42)
    estimates = [rng.normal(TRUE_MEAN, TRUE_STD, n).mean() for _ in range(n_repetitions)]
    results.append({
        'n':          n,
        'mean_est':   np.mean(estimates),
        'std_est':    np.std(estimates),
        'mae':        np.mean(np.abs(np.array(estimates) - TRUE_MEAN)),
        'theoretical_se': TRUE_STD / np.sqrt(n),
    })

df_sweep = pd.DataFrame(results)
print('Results (averaged over 500 repetitions per n):')
print(df_sweep.to_string(index=False))
